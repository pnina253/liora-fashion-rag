# Liora Fashion — בסיס ידע לפרויקט RAG

חנות אופנה דמיונית. כל התוכן נוצר לצורכי לימוד והדגמה בלבד, ואינו מתאר חנות פעילה.

## קבצים
- `knowledge_base/` — שישה קובצי Markdown המיועדים לטעינה למערכת RAG.
- `evaluation_questions.csv` — 15 שאלות בדיקה עם תשובות צפויות ומקורות. **אין לטעון את הקובץ הזה למאגר ה־RAG**; הוא נועד להערכה בלבד.

## הנחיות שימוש
1. טענו רק את ששת קובצי ה־Markdown שבתיקיית `knowledge_base`.
2. שמרו metadata של שם קובץ, כותרת סעיף וקוד מוצר כשאפשר.
3. השתמשו בקובץ השאלות כדי לבדוק תשובות ומקורות, כולל שאלות מרובות מקורות ושאלות ללא תשובה.
4. אל תציגו נתוני קטלוג כנתוני מלאי בזמן אמת.
5. תעדו לפחות שלוש תקלות **אמיתיות** שהתגלו בהרצות, עם תוצאות לפני ואחרי תיקון. אין להמציא תקלות מראש.

## כללי עקביות
- מחירים, צבעים, בדים ומידות מוצעות: `products.md` בלבד.
- מידות גוף והמלצות מדידה: `size_guide.md`.
- עלות וזמני משלוח: `shipping_policy.md`.
- החזרות: `returns_policy.md`.
- הזמנות ותשלומים: `orders_payments.md`.
- FAQ מפנה למדיניות ואינו יוצר תנאים חדשים במקומה.
- סף משלוח חינם: 299 ₪ לפי סכום מוצרים לאחר הנחות ולפני דמי משלוח.

## הערה
המסמכים אינם מדיניות משפטית או צרכנית לשימוש מסחרי. כתובת השירות והכתובת הפיזית דמיוניות.
